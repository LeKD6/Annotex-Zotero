Annotex for Zotero · Public beta

Reading notes that lead back to the source.

Turn saved highlights and comments into an editable Zotero note. Keep the author’s argument separate from your interpretation, and open the original passage when you need to check a claim.

Download for Zotero View source on GitHub

Free and open source. Tested on macOS with Zotero 10.0.9.

Install and start reading

  1. Download the .xpi. In Zotero, open Tools → Plugins and drag the file into that window.
  2. Select a paper and choose Open reading note in the Annotex section.
  3. When you’re ready to write, choose Export notes and bibliography.

AI is optional

Notes and exports need no account or API key. If you enable AI, use your own OpenAI or Anthropic API key. Define and Explain send the selected text and document title directly to your chosen provider when clicked. Summaries send the saved passages and notes for that reading. Annotex does not upload your PDF or route requests through its own service.
