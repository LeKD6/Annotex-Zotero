Annotex for Zotero · Public beta

Ask about a passage without leaving Zotero.

Annotex brings AI into the Zotero PDF reader. When you hit an unfamiliar term, a thicket of notation, or a paragraph you’ve read three times, select the part you’re stuck on and click Define or Explain. Keep your own reading notes linked to the pages you’ll want to come back to.

See it in Zotero

Install Annotex

  1. Click Download for Zotero above. Keep the downloaded .xpi file as it is.
  2. In the Zotero desktop app, open Tools → Plugins. Drag the file into the Plugins window, or click the gear and choose Install Plugin From File.
  3. Return to your library, select a paper, and open Annotex Open in the right-hand item pane.

Set up Define and Explain

  1. Open AI settings in Annotex and choose OpenAI or Claude (Anthropic). Paste a key from that provider’s API account into the API key field in Zotero. The provider may charge for requests.
  2. In Model ID from your provider, type the exact ID of the model you want. An ID is the name the API recognizes. For example, OpenAI lists GPT-6 Luna as gpt-6-luna. Find yours in the OpenAI model list or the Anthropic model list (use the Claude API ID).
  3. Check Enable AI and send requests when I click, then click Save AI settings. In the PDF reader, select the text you want help with and click Define or Explain.

Those buttons send the selected text and document title directly to the provider you chose. Summaries send the saved passages and notes for that reading. Annotex does not upload the PDF or send requests through its own service.

Keep a reading note

Choose Open reading note to start an editable Zotero note from your highlights and comments. When you’re ready to write, choose Export notes and bibliography. Both work without an API key.
